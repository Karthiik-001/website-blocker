# Website Blocker for Productivity

## Purpose

Website Blocker for Productivity is a beginner-friendly educational project for demonstrating website filtering and basic networking concepts.

The project is a single-page local website. It does not block websites on the computer or in a real browser.

## Features

- Add and remove domains from a block list
- Load sample websites
- Save the block list in browser `localStorage`
- Start and stop a Focus Mode countdown
- Test website access using a URL or domain
- Match blocked domains and their subdomains
- Display simulated blocked and allowed notifications
- Record access attempts in an in-memory access log
- Show blocked and allowed request counters

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Browser `localStorage`

## How to Run Locally

1. Open the project folder.
2. Double-click `index.html`.
3. Use the dashboard in your web browser.

No server, installation, or external dependencies are required.

## Important Limitation

Website blocking is simulated only. This project does not modify DNS settings, firewall rules, browser traffic, or operating-system networking. The displayed `127.0.0.1` redirection is only part of the on-screen demonstration.
